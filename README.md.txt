PROJECT DESCRIPTION

This project is developed in Java using Object Oriented Programming concepts.


FEATURES

. New Booking
. View All Bookings
. Search Booking
. View Drivers
. Calculate Revenue
. Save Bookings to File


OOP CONCEPTS USED

. Inheritance
. Abstraction
. Interface
. Encapsulation
. Polymorphism


OTHER CONCEPTS

. Exception Handling
. File Handling
. ArrayList
. Packages


PROJECT STRUCTURE

. models package
. payments package
. services package
. data package


HOW TO RUN

1. Open CMD in project folder

2. Compile using:

javac Main.java models/*.java payments/*.java services/*.java data/*.java

3. Run using:

java Main
